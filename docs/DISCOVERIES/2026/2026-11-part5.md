## [2026-11-19] Context Update — iOS "Your events" home
- **What changed:**
  - `EventCredentialStore.storedSlugs()`: the keychain store lists its own service's items with `kSecReturnAttributes` + `kSecMatchLimitAll`, so listing never reads a token. Accounts that aren't valid slugs are skipped.
  - `FeatureGuest/MyEventsModel`: an event counts as joined when it has a stored guest token. Each one is fetched with that token plus any unexpired grant. `eventNotFound` drops the event, `accessRequired` shows it as locked (opening asks for the PIN), and other errors keep it openable with the slug as its title. The list is sorted newest start first. Fetches run one after another, which is fine for a handful of events.
  - `HomeView` lists the events above the link field and reloads whenever home appears and on pull to refresh.
  - `AppNavigation.open(_:)` and `goHome()` drop any pending invite and reset the duplicate-link window. `GuestEventView` gains an optional `onHome` (a chevron in its top bar and above the join screen); the App Clip will pass nil. Leaving an event also returns home through `goHome()`.
- **Why:** Yassir asked for a proper app home (2026-11-19); a guest needs a way back to events they have joined.
- **Lessons:** `ImageRenderer` renders a `ScrollView` blank, so render the content without it when screenshotting from tests. `String(localized:)` follows the process locale, not `\.locale`.
