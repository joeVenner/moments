## [2026-11-28] Context Update: first TestFlight feedback
- **What changed:**
  - `BareButtonStyle` (`DesignSystem/Buttons.swift`) is the default button style, set by `momentsButtonDefaults()` at both app roots and on every sheet and full-screen cover. Menus take `.buttonStyle(.plain)`.
  - `VideoPosterLoader` reads a frame from a video file for videos with no still (`Media.posterSourceURL`); the grid and the viewer use it, and a video with no still stays playable.
  - `GuestEventHeader` has a banner (cover or `EventBannerScene`, colours from the web's `EVENT_BANNER_PRESETS`), counts, and `BannerIcon` buttons over it. `UploadStrip` shows the batch's progress; the uploads list opens after sharing.
  - `UploadView` and `UploadProgressView` use `SheetHeader` instead of a navigation bar; upload tiles show the prepared thumbnail.
  - `HomeView` is the landing; `HowItWorks` is shared with the welcome.
- **Why (causes found):**
  - The grey halos were the "Button Shapes" accessibility setting: iOS 26 draws a capsule behind every system-styled button (and underlines text buttons). A custom `ButtonStyle` or `.plain` is left alone. Reproduce in the simulator with `xcrun simctl spawn <id> defaults write com.apple.Accessibility ButtonShapesEnabled -bool YES`.
  - Environment button styles do not reach sheets or full-screen covers: each one needs `momentsButtonDefaults()` on its content. A `Menu` ignores a custom `ButtonStyle`.
  - Web uploads to R2 have no `poster_key`, so `viewerImageURL` was nil and the viewer stopped at "Couldn't load this moment". R2 video URLs have no file extension; AVFoundation plays them from the `video/mp4` content type and byte ranges (checked against production).
  - Host sign-in from the app answered 503 `sign_in_unavailable`: production's `EVENT_ACCESS_SECRET` exists but is blank. The web dashboard (Basic auth) doesn't need it, so it kept working. Private events answer 503 for the same reason.
- **Tooling:** with Xcode open on the project, it rewrites `Localizable.xcstrings`, `InfoPlist.xcstrings` and `project.pbxproj` after builds (reformatting, "stale" marks). Restore them before committing and add catalog entries by text. Simulator taps can be sent with CGEvent mouse clicks on the Simulator window.
- **Not checked:** live upload progress bars (local dev has no R2 secrets, so uploads fail there), and video playback inside the simulator.
- **Known, not from this change:** `PaletteTests.matchesTheWebTokens` fails since the landing added `bg-deep`, `ring` and `ring-strong` to the web theme.
- **Reference:** branch `fix/ios-testflight-feedback`.
